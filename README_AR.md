# StudyGen — النسخة الأولى

## ماذا يفعل؟
ترفع PDF أو TXT، والتطبيق يستخرج محتوى الدرس ثم يستخدم نموذج ذكاء اصطناعي لإنشاء:
- QCM
- أسئلة مباشرة
- صح/خطأ
- تمارين
- اختبار مختلط
ثم يعرض التصحيح والشرح.

## المتطلبات
1. Python 3.11 أو أحدث.
2. مفتاح OpenAI API.
3. اتصال بالإنترنت أثناء توليد الأسئلة.

## التشغيل على Windows
1. ثبّت Python.
2. افتح هذا المجلد.
3. انسخ `.env.example` إلى ملف اسمه `.env`.
4. افتح `.env` وضع مفتاح API مكان `ضع_مفتاح_API_هنا`.
5. شغّل `run_windows.bat`.
6. افتح الرابط الذي يظهر في المتصفح.

## ملاحظة مهمة
النسخة الأولى تعتمد على استخراج النص من PDF. إذا كان ملف الدرس عبارة عن صور/سكانر، قد لا يتم استخراج النص جيداً. الخطوة التالية هي إضافة OCR للملفات المصورة.

## تحسينات النسخة الثانية
- OCR للصور وPDF الممسوح.
- توليد تمارين حسابية أفضل.
- حفظ نتائج الاختبارات.
- نظام مراجعة ذكي للأخطاء.
- تقسيم الدرس إلى فصول قبل توليد الأسئلة.
- إنشاء امتحان من عدة ملفات.
- دعم الفرنسية والعربية والإنجليزية.
